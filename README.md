# Recipes as Tables

A library of world recipes drawn as TRN tables (Tabular Recipe Notation), with a converter for your own recipes.
Open `index.html`, or the GitHub Pages site of this repository.

This folder is generated: edit and build the project that produces it, then run `node scripts/publish.js` there.
Recipes, tables and photos stay © their authors and sources; each recipe links to its source, and the About
section of the page lists every source and its licence.
